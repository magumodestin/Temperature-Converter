Temperature Converter

A simple, responsive web app that converts temperatures between Celsius (°C) and Fahrenheit (°F) in real time.

Features

Convert Celsius to Fahrenheit and vice versa
Input validation with inline error messages
Clean, minimal UI with a full-screen animated video background
Fully responsive design

Built With

HTML5
CSS3
JavaScript (Vanilla)


Usage

Enter a temperature value in the input field.
Select the conversion type (°C to °F or °F to °C).
Click Convert to see the result instantly.
