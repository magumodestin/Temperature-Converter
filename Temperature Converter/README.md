# Temperature Converter

Oasis Infobyte SIP · Web Development & Designing · Level 1 · Task 3

An interactive web tool that converts a temperature between Celsius, Fahrenheit and Kelvin.

## Features
- Numeric input with validation (empty or non-numeric input shows an error)
- Unit selector: Celsius, Fahrenheit or Kelvin
- Convert button; the result shows all three units at once
- Absolute zero check: values below -273.15°C / -459.67°F / 0 K show a friendly error
- Clean, centred layout with clear labels and a looping video background

## Formulas
- K = °C + 273.15
- °F = (°C x 9/5) + 32
- °C = (°F - 32) x 5/9
- °C = K - 273.15

The script converts the input to Celsius first, then to the other two units.

## Tech stack
HTML5, CSS3, vanilla JavaScript
